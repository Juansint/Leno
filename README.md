# Leno · Landing page

Landing page responsive para **Leno**, una app ficticia de salud y productividad.

**[Ver demo](https://leno-sigma.vercel.app/)**

## Qué incluye

- Hero, testimonios, vista previa de la app y llamadas a la acción.
- Página de detalle (`details.html`).
- Diseño adaptado a móvil, tablet y escritorio.

## Tecnologías

`HTML` `CSS` `JavaScript`

## Ejecutar en local

Clona el repositorio y abre `index.html` en el navegador.
